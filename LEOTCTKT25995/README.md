# TicTakToe

**A simple two‑player Tic‑Tac‑Toe game built with React and Vite.**

## Features

- Local two-player mode (X vs O)
- 3×3 interactive grid
- Automatic turn switching; cells cannot be overwritten
- Turn indicator
- Win detection with highlighted winning line
- Draw detection
- Game‑over message & “New Game” button
- Responsive design for desktop & mobile
