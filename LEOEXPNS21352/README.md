# ExpenseTracker

A simple React application that lets you track expenses. Enter the name, date, and amount of each expense, and the app will display a list of all expenses and the total amount spent.

## Features
- Add expenses with **name**, **date**, and **amount**.
- View a list of all added expenses.
- Automatically calculate and display the **total** amount.

## Prerequisites
- Node.js (v14+) and npm installed on your machine.
